# 기억의 궁전 (Memory Palace App)

기억술 기법인 '기억의 궁전(Method of Loci)'을 활용한 웹 애플리케이션입니다.
제시어를 입력하면 자동으로 장소와 물건을 매칭하여 기억하기 쉽게 도와줍니다.

## 기능

- 여러 개의 단어를 한 번에 입력 가능
- 10개의 다른 장소 (현관, 거실, 부엌, 침실, 욕실, 서재, 발코니, 차고, 정원, 지하실)
- 각 장소마다 5개의 특징적인 물건
- 자동으로 생성되는 기억 스토리
- 시각적으로 아름다운 카드 형태의 UI

## 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. 기억하고 싶은 단어들을 쉼표로 구분하여 입력합니다
   - 예: `사과, 연필, 컴퓨터, 책, 자동차`
3. "기억의 궁전 생성" 버튼을 클릭합니다
4. 각 단어가 특정 장소의 물건과 연결된 카드가 생성됩니다
5. 스토리를 읽으며 연상 이미지를 머릿속에 그립니다

## 기억의 궁전이란?

기억의 궁전(Memory Palace) 또는 장소법(Method of Loci)은 고대 그리스 시대부터 사용되어 온 기억술입니다.

**원리:**
- 익숙한 장소를 머릿속에 떠올립니다
- 기억할 정보를 그 장소의 특정 물건이나 위치와 연결합니다
- 나중에 그 장소를 머릿속으로 걸어가며 정보를 회상합니다

**효과:**
- 공간 기억은 언어 기억보다 강력합니다
- 연상 이미지를 통해 장기 기억으로 전환됩니다
- 많은 정보를 순서대로 기억할 수 있습니다

## 팁

- 더 생생한 이미지를 만들수록 기억이 잘 됩니다
- 과장되고 우스꽝스러운 상황을 상상하면 더 효과적입니다
- 정기적으로 반복해서 회상하면 장기 기억으로 전환됩니다
- 자신만의 스토리를 추가로 만들어도 좋습니다
